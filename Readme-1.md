# Fit Web

## Project Description

Fit Web is a modern fitness and workout management website. Users can browse different workouts, view workout details, save workouts for later, and add workouts to their daily plan.

## Technologies Used

* Next.js
* React
* JavaScript
* Tailwind CSS
* DaisyUI
* Context API
* HTML5
* CSS3

## Key Features

### 1. Workout Library

Users can browse a collection of different workouts with useful information such as duration, equipment, calories burned, and rating.

### 2. Workout Details

Users can open a workout and view its detailed information.

### 3. Today's Plan

Users can add workouts to their daily plan and see the selected workouts in the Plan section.

### 4. Save for Later

Users can save their favorite workouts for later and remove them from the saved list when needed.

### 5. Mark Workout as Done

Users can mark a workout as completed after finishing it. The completed workout button becomes disabled to prevent repeated actions.
